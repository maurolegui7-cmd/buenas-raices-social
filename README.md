# Buenas Raíces Formosa — piezas para redes

Repositorio público que aloja las imágenes de las publicaciones de
[Buenas Raíces Formosa](https://www.buenasraicesformosa.com.ar).
Las piezas se sirven por URL pública para que Metricool pueda descargarlas
al programar cada post.

## Estructura

- `instagram/` — piezas listas, 1080×1350 px
- `scripts/` — generadores en Python (Pillow) y el logo de marca

## URL pública de una pieza

```
https://raw.githubusercontent.com/maurolegui7-cmd/buenas-raices-social/main/instagram/<archivo>.png
```
